# sheetmate-app

구글 시트 «주문 알림» 관리 화면(정적 페이지). 데이터는 각 가게의 구글 시트(Apps Script)에 있고,
이 페이지는 주소 `#` 뒤의 배포 id·링크 토큰으로 그 시트의 API 를 부르기만 한다.
비밀값·고객 데이터는 이 레포에 없다.

- 왜 따로 두나: 구글 주소에서 화면을 띄우면 브라우저에 구글 계정이 여러 개 로그인돼 있을 때
  «현재 파일을 열 수 없습니다» 버그가 난다. 다른 사이트에서 부르면 구글 쿠키가 안 붙어서 생기지 않는다.
- 원본: 비공개 레포 `order-reminder-sheet` 의 화면을 생성해서 둔다.
